# PACE

Wersja PACE z poprawkami układu mobilnego i gestu powrotu dla iPhone’a.

## Aktualizacja
- Lepsze skalowanie na ekranach iPhone’a i obsługa bezpiecznych obszarów (notch / Dynamic Island / dolny pasek).
- Gest przesunięcia od lewej krawędzi w prawo: powrót do poprzedniego poziomu aplikacji.
- Poprawione odstępy i rozmiary elementów na małych ekranach.

Opublikuj zawartość archiwum w katalogu głównym repozytorium GitHub Pages.
